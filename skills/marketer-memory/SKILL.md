# Memory management

Read `../marketer/reference/memory.md`, `data-model.md`, and `ownership.md`. Write only `.marketer/memory.md`.

## Procedure

Add a memory entry only when a source mission/experiment/evaluation supports a concise lesson that could influence future strategy or process. Include confidence, counterevidence, and a review/expiry condition. Link to source artifacts and preserve `unknown` where causality or generality has not been established.

Do not copy source evidence, retain credentials/personal data, set mission routes, or promote a single manual observation into a global rule. Remove nothing; supersede stale guidance through a later entry with its rationale.

Return `complete` with the memory ID, `needs_input` when provenance is absent, or `blocked` when the proposed fact belongs to an external canonical evidence system.
