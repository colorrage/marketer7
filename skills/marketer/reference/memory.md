# Sparse memory discipline

`memory.md` is an append-only index of reusable lessons, not a transcript. Add an entry only when it can influence a future mission, audience, channel, measurement approach, or safety rule.

Each entry contains a memory ID, date, concise lesson, confidence, source mission/experiment/evaluation path, and expiry or review condition. Preserve counterevidence and uncertainty. Do not elevate a single simulated result to a general rule, and never write credentials, personal data, or unverified claims into memory.

Mission-local history stays with the mission and experiment artifacts. A handoff captures current operational context; it is not automatically promoted to durable memory.
